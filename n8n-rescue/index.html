Questions

Before you send it

Is it safe to send my workflow?

n8n's workflow export doesn't include your credential secrets, only their names. Still, remove any API keys or personal data you've pasted directly into nodes before sending. We only use what you send to fix the workflow.

Do you need access to my n8n?

Usually not. The export plus the error message is enough for most fixes, and you import the corrected file yourself. If a fix needs your instance (for example a server problem), we'll ask first and explain why.

What if you can't fix it?

Then you owe nothing. We'll tell you what we found so the time isn't wasted.
